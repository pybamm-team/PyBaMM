Converting a state vector to CasADi without `y`, or a time derivative of a state (e.g. `symbol.diff(pybamm.t)`) without the state derivatives `y_dot`, raises `pybamm.ModelError` instead of `ValueError`. The Rust backend raises the same error for a missing `y_dot`, as does `solution.observe` of a time derivative. To migrate, catch `pybamm.ModelError`.
