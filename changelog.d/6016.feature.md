`pybamm.step.ControlStep` lets experiment steps drive any model parameter, setting it to a value or adjusting it to zero a residual, in both experiment modes. On battery models, a control step that does not drive `"Current function [A]"` rests. The unified mode reads `"Ambient temperature [K]"` only if the model does, and runs battery steps on models that are not battery models. Experiment steps upsample the model's own `upsampling_variable` when it has no variable of the step's. Closes [#6015](https://github.com/pybamm-team/PyBaMM/issues/6015).
